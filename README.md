# Vinsight リプレイス – デモ

Vinsight（モニター／アンケートサイト）のリプレイス・デモです。**データベースなし**・**ダミーデータ**で、モニターサイトと管理画面の全機能が動きます。
要求事項（`③Vinsight_要求事項（案）.xlsx` の全35行）をすべて実装しています。

## 起動

```bash
npm install      # 初回のみ（node_modules は同梱済み）
npm run dev      # ビルドしてから起動します（初回は約1分）。 http://localhost:3000
```

`npm run dev` は **本番モード**（`next build && next start`）で起動します。メニューを素早く何度クリックしても固まらず、画面遷移が即座に行われます。
（開発用のホットリロード版 `next dev` は、各ページの初回表示ごとにコンパイルが走るため、クリック直後に反応しないことがあります。ソースを編集するときだけ `npm run dev:hot` を使ってください。）
コードを変更した後は、起動中のサーバーを止めて（Ctrl+C）`npm run dev` を再実行してください。

## デモ用ログイン

| 画面 | URL | ID | パスワード |
|---|---|---|---|
| モニター（マイページ） | `/`（ログイン） | `demo@vinsight.example`（または モニター番号 `1001`） | `monitor123` |
| 管理画面 | `/admin/login` | `admin` | `admin123` |

他のダミーモニター（1002〜）も同じパスワード `monitor123` です（例：`user1002@example.com`）。

## 構成

```
public/images/           クライアント提供のイラスト（トップのメインビジュアルに使用）
src/app/(site)/          モニターサイト：トップ・登録・マイページ・問い合わせ など
src/app/admin/           管理画面（A〜G ＋ 新設メニュー）
src/app/api/[...path]/   REST API（単一ハンドラ → src/server/dispatch.ts）
src/server/store.ts      インメモリのダミーデータ（サーバー再起動で初期化）
src/server/routes-*.ts   API ルート（site / admin）
src/server/validate.ts   入力規制（半角・全角など）
src/styles/site.css      モニターサイトのデザイン（ビザビ公式サイトに準拠）
src/styles/admin.css     管理画面のデザイン
```

- データはメモリ上にのみ保持されます。管理画面左下の「デモデータをリセット」で初期状態に戻せます。
- メールは**実際には送信されません**。送信内容は管理画面の「送信メール履歴」に記録されます。
- 管理画面の「**要求事項 対応状況**」で、35項目それぞれの実装箇所へ移動できます。

## デザインについて

クライアント（ビザビ）の世界観――黄・橙・青・緑の配色、Jost + Noto Sans JP、アウトライン調のイラスト――は引き継ぎつつ、
公式サイトとは**意図的に別のデザイン**にしています（「ステッカー」調）。

- ヘッダー：画面上に浮かぶカプセル型。スクロールで隠れ、戻ると再表示
- ボタン・カード：太い黒枠＋ずらした影のステッカー風
- トップ：濃紺のヒーロー（イラストを「窓」に入れてマウスで視差）、斜めのティッカー、ベントー型タイル、ステップ、チケット型のギフト、タブ式ログイン、横スクロールのお知らせカード、FAQ、黄色のお問い合わせ、アウトライン文字のフッター
- マイページなど内側のページも、同じ「ステッカー」調に統一

イラストは `public/images` の画像をそのまま使用しています。スタイルは `src/styles/home.css`（サイト全体のデザイン：白とグレー、青のアクセントによるシンプルなデザイン。画像・アニメーションなし）と `src/styles/site.css` / `polish.css`（フォーム・表など）です。
